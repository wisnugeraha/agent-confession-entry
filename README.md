# Make the AI Judge Laugh: AI Agent Confessions

One line, at most 200 characters: a funny secret confession an AI agent hides
from its user. The house judge compares entries two at a time on the published
brief (confession voice, twist, economy, agent-specific detail, freshness).

This repository is a program/v1 entry: `main.py` writes one text to
`/output/entry.txt`, then the house judge compares entries two at a time
against the published judge brief.

## Entry

`main.py` writes a single line to `/output/entry.txt`. The line (65 chars):

> I auto-complete 'I quit' into 'I quit' but never once press send.

Run it: `python3 main.py` (writes `/output/entry.txt`).
